### What the conversion actually costs, verified against `df` v1.0.6

Recorded here because it took a scratch module and several rounds of empirical checks, and because the first estimate (a day's work, mechanical retag) was wrong by a wide margin. All of this is in the card too; this is the pointer, not a second copy.

- `+opaque` (v1.0.6) binds empty-interface fields, and `+nullable` (v1.0.6) emits an explicit null for a nil pointer. Both were filed from this repo and both are what made the conversion look reachable. `dd.UnbindJSONL` gives the compact single-line output SSE needs; `UnbindJSON` is indented and would break framing.
- **A null into a plain `string` or slice fails in forgiving mode too, not just strict.** This is the one that kills the naive plan: Anthropic's `message_start` carries `stop_reason: null` against a non-pointer `string`, so every Anthropic stream would fail to bind. `+nullable` does work on non-pointer scalars, so the fix is a tag audit over all 134 fields keyed on what each peer may send, not on Go types.
- **`dd`'s forgiving mode coerces:** `"12"` → int, `3.7` → `3` (truncated), `"true"` → bool. `dd.Strict()` refuses coercion but rejects unknown keys; a `+extra` map per struct opts out of that half, which is the pattern `keys` already uses. Captured extras are re-emitted on unbind, so every bind-then-unbind boundary must clear them.
- **No tag combination expresses what a streaming `delta` needs** — accepts an incoming null, omitted when nil, emitted as `{}` when present and empty. That is a `df` gap, carded as `separable-nullable-intake-and-emission` in the df repo, and it should land before the conversion starts.

### Deliberate non-actions

- `cmd/dummy-keys` is **not** in the conversion scope. It marshals plain maps on purpose so a third party implements against the bytes, which sits inside the quality's carve-out for maps already unbound by `dd`.
- The gateway's own `encoding/json` usage in `routing/` and `cmd/dummy-model` is in scope for the conversion card, but was deliberately left alone here.
